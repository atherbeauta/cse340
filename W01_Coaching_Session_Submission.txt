--- Express Routing (Discussion + Snippet) ---
AI: Express routes define HTTP endpoints and their handlers. We also use middleware for shared data (like the dynamic year).
Student: Show the server.js snippet you used.
AI: Here is the relevant snippet from `server.js` used in this project:

```js
// Provide the current year to all templates dynamically
app.use((req, res, next) => {
    res.locals.year = new Date().getFullYear();
    next();
});

// Home route
app.get('/', (req, res) => {
    res.render('index', { title: 'Home' });
});

// Categories route
app.get('/categories', (req, res) => {
    const categories = ['Environment', 'Educational', 'Community Service', 'Health & Wellness'];
    res.render('categories', { title: 'Categories', categories });
});

// Organizations route
app.get('/organizations', (req, res) => {
    const organizations = [
        { name: 'Pathway Promise', image: '/images/org-1.svg', description: 'Supporting students with mentorship.' },
        { name: 'Campus Care Collective', image: '/images/org-2.svg', description: 'Wellness programs and volunteering.' },
        { name: 'Innovation Impact', image: '/images/org-3.svg', description: 'Service and technology projects.' }
    ];
    res.render('organizations', { title: 'Organizations', organizations });
});
```

AI: Key points — middleware runs before route handlers; `res.locals` exposes values to EJS views; routes call `res.render(view, data)` to render templates with data.

--- JavaScript Language Principles (Discussion + Snippet) ---
Student: Briefly explain the JS principles used and show a simple function.
AI: We used modern JS patterns: `const`/`let` scoping, arrow functions, higher-order functions (callbacks), and asynchronous code with `async/await` or Promises when needed. Here's an illustrative snippet showing closure and async behavior:

```js
// Example: asynchronous data fetch and callback handling
async function fetchOrganizations(fetchFn) {
  try {
    const res = await fetchFn('/api/organizations');
    const data = await res.json();
    return data;
  } catch (err) {
    console.error('Fetch failed', err);
    throw err;
  }
}

// Usage with a passed-in fetch function (dependency injection for testability)
fetchOrganizations(window.fetch).then(orgs => {
  console.log('Loaded', orgs.length, 'organizations');
}).catch(()=>{});
```

AI: Key notes — prefer `const` for values that don't change, `let` for reassignable variables; use `async/await` to keep asynchronous code readable; inject dependencies for easier testing.

--- EJS Partials and Pages (Discussion + Snippet) ---
Student: How do partials and pages fit together?
AI: EJS partials are reusable fragments (header, footer) included in multiple pages using `<%- include('partials/header') %>`. Pages render with `res.render` and get access to `res.locals` values.

AI: Example `header.ejs` include usage and a new `organizations.ejs` page snippet:

```ejs
<!-- In a page (e.g., organizations.ejs) -->
<%- include('partials/header') %>

<main class="page-content organizations-page">
  <section class="section-header">
    <h2>Community Organizations</h2>
    <p>Meet the organizations in our community.</p>
  </section>

  <ul class="organization-grid">
    <% organizations.forEach(function(org) { %>
      <li class="organization-card">
        <img src="<%= org.image %>" alt="Logo for <%= org.name %>">
        <h3><%= org.name %></h3>
        <p><%= org.description %></p>
      </li>
    <% }); %>
  </ul>
</main>

<%- include('partials/footer') %>
```

AI: The `footer.ejs` uses the dynamic year provided by the middleware: `&copy; <%= year %> BYU-Pathway Worldwide`.
